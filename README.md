### 🚀 About Me

I build at the intersection of **Frontier AI Systems (Reinforcement Learning, Agent Safety, AI4Science)** and **Low-Level Systems Programming (Operating System Internals, Memory Allocators, Virtual Machines, C/Rust)**.

I believe that building truly reliable, safe, and scalable autonomous agents requires end-to-end mastery across the entire compute stack — from memory layout, CPU/GPU hardware boundaries, and POSIX syscalls all the way up to frontier model architectures and reinforcement learning evaluation environments.

- 🔬 **AI & Safety Focus:** Agentic RL evaluation harnesses, empirical frontier model benchmarking (GPT-5.5), AI for Science (molecular deep learning, GNNs, Bayesian Optimization).
- ⚙️ **Systems & Core Focus:** OS kernels from scratch, custom memory allocators (`malloc`/`free`), virtual machine architectures, and high-performance Unix tooling.
